Entry for [Loading Screen Gold: A Tip in 200 Characters](https://make.fun/bounty/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270) on make.fun — one sharp, funny loading-screen tip for stressed developers and AI coding agents, in 200 characters or fewer.

> Tip: when the build bar stalls at 87%, don't refresh — my agent and I blame the 412-line npm log and wait to see who blinks first.

## Why this line

The build wait is the one moment a developer and their coding agent are doing exactly the same thing: staring at the same stuck bar, neither able to speed it up. The tip pretends to be practical advice ("don't refresh") and then admits the real coping strategy — blaming the log and turning the wait into a staring contest neither side can win, since an agent cannot blink and a tired developer at 3 a.m. barely can. Three concrete anchors (87%, a 412-line npm log, the blink) keep it specific instead of a generic "be patient" platitude, and the turn lands in the final clause, where the reader realises the joke is about both of them at once.
